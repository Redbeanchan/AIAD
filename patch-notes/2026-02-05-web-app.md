# Patch notes – 2026-02-05

## What changed today

- We set up the **first version of the background-removal web app**.
- We created a **backend service (API)** that actually removes the background from images.
- We created a **simple web page (UI)** where you can upload an image and see the result.

## In plain language

- There is now a **small website** you can open on your computer that lets you:
  1. Pick an image from your files.
  2. Send it to our server.
  3. Get back the **same image but with the background removed**.

- The server uses an open‑source **AI background remover** called `rembg` under the hood.  
  You don’t need to know the details – just that it is a well-known tool for cutting the subject out of photos.

## How to try it (high level)

- Start the **backend service** (the part that runs the AI model).
- Start the **web page**.
- Open the page in a browser and upload a photo.

The technical README in the project has the exact commands for developers, but from a non‑technical point of view:  
**“We now have a working background-removal web app running locally.”**
